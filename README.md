# 云迹 · 智慧旅游推荐系统

基于 Vue 3 + Vite + Element Plus + ECharts 的课程答辩演示系统。

## 启动

```bash
pnpm install
pnpm dev
```

演示账号：`admin`，密码：`123456`（前端演示环境，非真实鉴权）。

演示路线

1. 登录后展示智慧总览的数据大屏与 AI 经营洞察。
2. 在目的地资源中筛选、新增或编辑一个景点，说明本地持久化。
3. 进入 AI 智能行程，修改城市、天数、人数和偏好并生成行程。
4. 在订单中心确认待处理订单，打开订单详情与核销凭证。
5. 在运营管理切换游客、内容、工单和角色权限。
6. 最后进入数据洞察，以 ECharts 图表总结系统价值。

## 功能模块

- 登录与路由鉴权
- 智慧运营总览
- 目的地资源 CRUD、筛选与本地持久化
- AI 行程模拟生成与预算分析
- 订单检索、审批、退款与详情
- 游客、内容、工单、角色权限管理
- 经营趋势、目的地能力和 AI 策略分析
